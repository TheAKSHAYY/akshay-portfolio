# akshay-portfolio
Akshay's personal portfolio website showcasing projects and experience.

## Deploy on GitHub Pages

1. Push this repository to GitHub.
2. In the repository settings, open **Pages** and set **Source** to **GitHub Actions**.
3. Push to `main` (or run the workflow manually) to trigger deployment.
4. Your site will be available at:
   `https://theakshayy.github.io/akshay-portfolio/`
