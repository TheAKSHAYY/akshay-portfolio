# akshay-portfolio
Akshay's personal portfolio website showcasing projects and experience.

## Deploying to GitHub Pages

- This project is configured for project-site deployment at `https://theakshayy.github.io/akshay-portfolio/`.
- Push to `main` (or run the **Deploy to GitHub Pages** workflow manually) to build and deploy.
- In repository settings, ensure **Pages** uses **Build and deployment → Source: GitHub Actions** if it is not already set.
